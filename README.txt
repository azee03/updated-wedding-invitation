THASNIM & MUHAMED UVAIS — WEDDING INVITATION WEBSITE

FILES
- index.html       Cover page with glowing seal and envelope-opening transition
- invitation.html  Wedding details, photograph, countdown, and music control
- style.css        Responsive styling, consistent cover centering, opening animation
- script.js        Seal motion, page navigation, letter-opening effect, countdown, music
- images/wedding-hands.jpeg  Wedding photograph used on the invitation page
- music/background.mp3      Your uploaded background music (about 4 min 34 sec)

RUN LOCALLY
Keep all files and the images and music folders together. Open index.html in a browser.
Click the M & T seal to see the envelope open before the invitation page loads.

GITHUB PAGES
Upload the files to the repository root and keep images/wedding-hands.jpeg in the images folder and music/background.mp3 in the music folder.

MUSIC
The uploaded track is included locally at music/background.mp3, so the invitation no longer depends on the reference website for its music file. Some browsers block autoplay; use the Play music button if playback does not start automatically.
RESPONSIVE COVER
The cover uses dynamic viewport units and safe-area padding. Its main card is centered independently from the footer when there is enough space; on very short screens the page remains scrollable rather than clipping the content.
